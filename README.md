# Dashboard BancoEstado - Marketing Cloud

Dashboard interactivo para proyección de consumibles de Marketing Cloud (Supermensajes y WhatsApp) con simuladores de escenarios y propuestas de crecimiento.

## 🚀 Uso

Simplemente abre el archivo principal en tu navegador:

```bash
open index-branded.html
```

## 📊 Características

### WhatsApp
- **Indicadores**: Contratado, Proyección a Dic 2026 y Dic 2027
- **Simulador de Casos de Uso**: 6 categorías configurables
- **Toggle Recurrente/One-time**: Define si cada caso se repite mensualmente o es único
- **Selector de mes**: Para casos One-time, elige en qué mes impacta
- **Gráfico de Proyección**: Hasta Diciembre 2027
- **Propuestas Interactivas**: 2 propuestas seleccionables que ajustan el gráfico

### Supermensajes
- **Indicadores**: Contratado (5 años), Utilizado, Disponible, Promedio Mensual
- **Gráfico Anual**: Proyección Junio 2025 - Mayo 2030
- **Propuesta Interactiva**: Hasta Dic 2026 con capacidad incremental
- **Alertas Dinámicas**: Cálculo automático de sobrepaso

### Vista Consolidada
- **3 Propuestas Seleccionables** (WA 2027, WA 2026, SM 2026)
- **Resumen Automático**: Total de inversión y propuestas activas

## 🎨 Diseño

Branding Salesforce con tipografía Montserrat + Inter y paleta oficial.

- Datos embebidos
